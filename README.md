Courework project for CIE A-level Computer Science demonstrating OOP concepts: create classes with appropriate attributes and methods, create and use objects from defined classes, apply inheritance to create a subclass from a parent class, use inherited and specialised attributes/methods.

# CIE A-Level Computer Science Coursework Project

## 📌 Project Overview
This repository contains my practical coursework project developed for the **CIE A-Level Computer Science** syllabus. The project focuses on solutions and implementation for a practical system development task focused on inventory management for electronic devices. It demonstrates core OOP practices, data encapsulation, and class inheritance hierarchies.

## 🛠️ Tech Stack & Concepts Used
- **Language:** Python 3
- **Core Concepts:** Object-Oriented Programming (OOP)

## 🚀 How to Run the Program
1. Ensure you have Python installed.
2. Clone or download this repository.
3. Run the main file using:
   ```bash
   python main.py
   ```
